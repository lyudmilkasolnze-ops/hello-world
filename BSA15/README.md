Этот проект посвящен анализу и проектированию REST-интеграций для системы онлайн-записи в барбершоп, где на примере двух сценариев использования необходимо актуализировать бизнес-процессы, определить справочники и способы их интеграции, описать подходящие HTTP-методы с примерами запросов и ответов, выполнить маппинг данных между системами и сообщениями, а также детально проработать обработку ошибок с указанием условий проверки, кодов ошибок и критичности.

Этот проект посвящён управлению требованиями, тестированию и постановке задач в разработке программного обеспечения. Участники учатся выделять разные типы требований (бизнес-требования, требования пользователей, функциональные и нефункциональные), назначать им идентификаторы, атрибуты и статусы, а также отслеживать связи между ними. На примере функционала автоматического напоминания клиентам о записи в сервис нужно зарегистрировать требования в системе управления задачами, создать позитивные и негативные тест-кейсы для проверки этого функционала, а затем оценить результаты тестирования и при необходимости оформить отчёты о дефектах. В итоге проект даёт навыки работы с полным циклом управления требованиями - от регистрации до проверки качества через тестирование.

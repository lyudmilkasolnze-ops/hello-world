Этот проект посвящён нефункциональным требованиям (НФТ) — тому, как система должна работать, а не что она должна делать.

В рамках проекта нужно:

Научиться выявлять и формулировать НФТ (производительность, безопасность, масштабируемость и т.д.)

Классифицировать их по типам

Применять эти знания к двум практическим задачам:

Онлайн-запись в барбершоп
Служба доставки заказов
Для каждой задачи нужно определить приоритетные НФТ, атрибуты производительности, доступности, масштабируемости, безопасности и требования к логированию.

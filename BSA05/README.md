В этом проекте я научилась моделировать требования к ИТ-системам с помощью графических и табличных методов: строить диаграмму потоков данных (DFD) уровня 0, отражающую движение данных между внешними сущностями, процессами и хранилищами; создавать межфункциональную диаграмму «плавательные дорожки» (swimlane) для описания бизнес-процессов по ролям с шагами, переходами и решениями, а также дополнять её создаваемыми артефактами; разрабатывать диаграмму и таблицу состояний для объектов, имеющих жизненный цикл, указывая события переходов, инициаторов и условия. Кроме того, я научилась формулировать цель построения каждой диаграммы и различать области рассмотрения — текущее состояние (as is) и проектируемое (to be).

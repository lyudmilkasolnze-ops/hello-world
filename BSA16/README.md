Этот проект посвящен изучению интеграции информационных систем с использованием протокола SOAP, форматов XML и WSDL на примере создания двух веб-сервисов для базы данных клуба любителей домашних животных. В ходе выполнения заданий необходимо проанализировать структуру WSDL-документов, определить назначение основных тегов и операций, разобрать схему данных XSD, выполнить обратное проектирование для описания требований к входным и выходным сообщениям, а также указать адреса endpoint для каждого сервиса.
